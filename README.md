# ⚔️ United Force • Event Manager Bot

Профессиональный Discord-бот, разработанный для организации внутриигровых активностей (сборов, ZvZ рейдов, роумов), автоматического ведения логов посещаемости, интеграции с **Google Sheets** и расчета финансовых долей участников (splits) гильдии **United Force** в Albion Online.

---

## 🚀 Основные возможности

*   **🎛️ Интерактивный UI:** Удобные Embed-карты с динамическими кнопками для быстрой записи участников на определенные роли/слоты.
*   **📂 Авто-создание веток (Threads):** Все регистрационные сообщения и логи активности перенаправляются в автоматически создаваемую **ветку сбора**, предотвращая спам в основных каналах.
*   **📊 Синхронизация с Google Таблицами:** Полная двусторонняя интеграция с Google Sheets (таблицы `UF`, `Log`, `Balance`) для учета посещаемости членов гильдии и автоматического форматирования данных.
*   **💰 Финансовые доли (Splits):** Мощный бухгалтерский функционал для начисления долей участникам контента, отслеживания личного баланса, подачи заявок на вывод средств и архивации истории.
*   **⚖️ Система балансов «Грев»:** Интеграция с выделенной вкладкой Google Sheets `Grev` (ID `791255482`). Считывает Discord ID и ручные правки балансов, парсит лог-файлы сейфа гильдии (.txt), автоматически распределяет транзакции и осуществляет реальный Discord-пинг должников с балансом менее 100 монет.
*   **⏰ Умные напоминания о старте**: Оповещение участников о начале сбора за 15 минут с автоматическим подавлением лишних пингов, если сбор создается незадолго до старта.
*   **⏱️ Динамическое время завершения**: Отчет об автоматическом закрытии сбора выводит точное время его проведения на русском языке с соблюдением правил склонения (например, *«прошло 15 минут»*, *«прошел 1 час»*, *«прошло 2 часа»*).
*   **🛡️ Интерактивная система региров (Regears):** Удобная подача заявок на компенсацию экипировки с автодополнением всей экипировки (оружие, левая рука, голова, тело, ноги, плащ) на русском языке и поддержкой боевых маунтов. Панель управления с автоматическим скрытием кнопок: после одобрения кнопки "Одобрить" и "Отклонить" убираются с панели (остается только "Выдано"), а после отклонения или выдачи все кнопки полностью скрываются.
*   **🌀 Авалонские порталы:** База данных и команды для быстрого поиска характеристик авалоновских локаций с автодополнением по 320+ картам и синхронизацией с Google Таблицей.
*   **⚡ Быстрые команды:** Поддержка сообщений `.+[номер]` / `.-[номер]` внутри веток сбора для молниеносной регистрации без использования интерфейса.

## 🛠️ Слэш-команды бота (Slash Commands)

> [!NOTE]
> Все основные команды бота переведены на современный формат слэш-команд Discord (`/`).

### 👥 Для всех участников гильдии
*   `/balance [user]` — Показывает текущий финансовый баланс (свой или выбранного игрока).
*   `/withdrawal_request` — Подает заявку на вывод средств (уведомляет администраторов в настроенном канале).
*   `/activity [period]` — Выводит количество посещенных контентов за период (week / month / число дней).
*   `/check_grev [user]` — Просмотр балансов системы «Грев» в реальном времени. Если `user` не указан, выводит полный отчет, реально пингуя участников с балансом < 100 на сервере.
*   `/info` — Справочное меню со списком команд для обычных пользователей.
*   `.+[номер]` / `.-[номер]` — Быстрая запись/выписка внутри созданной ветки сбора (текстовые команды).

### 🎖️ Для организаторов событий (в ветке сбора)
*   `!+[номер] @User` — Принудительно вписать игрока на указанный слот (текстовая команда).

### 🔑 Для администраторов (Управление и Настройки)
*   `/call` | `/zvz` | `/roum` — Создать соответствующий сбор с помощью интерактивного окна.
*   `/call_setting` | `/zvz_setting` | `/roum_setting` — Быстрое создание сбора через параметры.
*   `/config_call` | `/config_zvz` | `/config_roum` — Настройка разрешенных каналов и ролей доступа для событий.
*   `/config_user [channel]` — Настройка канала для пользовательских команд.
*   `/config_sheet [URL]` — Привязать новую Google Таблицу по ссылке.
*   `/uf` — Синхронизация участников Discord-сервера с таблицей `UF` + автосортировка.
*   `/balance_update` — Сверка и добавление новых участников сервера в таблицу `Balance`.
*   `/balance_archive` — Архивация текущих балансов в архивную колонку и очистка контентных столбцов.
*   `/split` — Удобное начисление долей за контент через интерактивное окно с предварительным автобэкапом таблицы.
*   `/balance_uf` — Вывод таблицы балансов всех участников в виде текста или `.txt` файла.
*   `/balance_uf_teg` — Пинг всех участников с балансом более 1 000 000.
*   `/withdraw_money [ID]` — Провести снятие денег (выдачу средств) и обнулить баланс указанного пользователя.
*   `/set_withdraw [channel] [role]` — Настроить канал и роль для уведомления о заявках на вывод средств.
*   `/update_grev [file]` — Синхронизация таблицы «Грев» с слиянием ручных правок и импортом логов сейфа гильдии `.txt`.
*   `/info_ad` — Панель администрирования со списком всех команд управления.

## ⚙️ Установка и запуск

### 1. Требования
*   Python 3.10+
*   Токен Discord-бота
*   Файл авторизации Google Cloud Service Account (`credentials.json`)

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Конфигурация
1.  Создайте файл `.env` в корневой директории бота и пропишите токен: `DISCORD_TOKEN=ваш_токен_здесь`
2.  Положите ваш файл `credentials.json` в корень папки `call_UF/`.
3.  Запустите бота один раз и настройте Google Таблицу с помощью команды `/config_sheet`.

### 4. Запуск бота
```bash
python main.py
```
